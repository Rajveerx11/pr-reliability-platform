# PR Reliability Platform

Private, approval-first GitHub App for evidence-backed AI pull request review.

Current state: version-one core is merged. Production provider wiring, repository onboarding,
measured evaluation, release artifacts, and live private-VM acceptance remain open.

This product is an AI pull request reviewer. It uses selected CI-style checks as review evidence;
it is not a general CI/CD system or GitHub Actions replacement.
