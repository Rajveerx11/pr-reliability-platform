Hard-to-reverse choices

Decide early

These choices affect stored data, security, or every future agent.

Workflow

Temporal from first vertical slice

Durable retries, cancellation, timers, and human waits belong in workflow history, not ad-hoc background jobs.

Agent output

Versioned JSON contract

Agents return findings, evidence, confidence, and proposed action. Free-form prose is presentation only.

Ownership

GitHub installation is tenant boundary

Every repo, run, artifact, and approval resolves through one installation and owner.

Writes

Idempotency key per external action

Publishing uses run_id + action_type + target_sha. Retries cannot post twice.

Evidence

Fail closed

If tests, sandbox, or Proof of Work cannot complete, finding stays unpublished and run shows why.

Secrets

Short-lived scoped tokens

Workers receive only repo-specific, time-limited access. Prompts and logs never store secrets.

Implementation plan

Baseline before specialists

Open each phase. Each ends with a checkable result.

Phase 0Today · 1 day
Freeze contracts and scaffold repo
  • Create service, worker, web, infrastructure, and evaluation folders.
  • Write version-one run state, finding JSON, webhook event, and approval contracts.
  • Create one tiny PR fixture with one known bug.

Done: local command creates one queued run from fixture metadata.

Phase 1Week 1
Prove single-agent local baseline
  • Select changed files plus direct imports under fixed token budget.
  • Run one provider through a narrow ModelClient interface.
  • Validate structured findings; record tokens, duration, and exact reported cost.

Done: agent finds seeded defect and emits valid evidence JSON.

Phase 2Week 2
Add GitHub and durable orchestration
  • Verify webhook signature before parsing payload.
  • Deduplicate deliveries and start one Temporal workflow per head SHA.
  • Support timeout, retry, cancellation, and superseded-commit handling.

Done: closing or updating PR safely cancels or replaces run.

Phase 3Week 3
Add sandbox, evidence gate, and approval
  • Run tests in disposable container with CPU, memory, time, filesystem, and network limits.
  • Wrap existing Proof of Work gate behind stable adapter.
  • Show verified findings; require approval before a commit-bound GitHub review.

Done: retry posts at most one approved review.

Phase 4Week 4
Measure reliability
  • Add traces for model calls, tools, retries, waits, latency, and cost.
  • Build 10 golden PR tasks; label true defects and allowed findings.
  • Publish baseline defect recall, false-positive rate, latency, and cost.

Done: repeatable HTML report with honest unknowns.

Phase 5After baseline
Test specialist agents, then deploy
  • Add test and security specialists behind routing rules.
  • Compare single-agent and multi-agent runs on same frozen corpus.
  • Keep specialists only when benefit beats cost and latency thresholds.
  • Deploy, run on five external repos, collect 100 real runs.

Done: public comparison, threat model, runbook, dashboard, demo, and postmortem.

MVP includes

One trustworthy review path

  • One GitHub organization and installation flow.
  • One single-agent analyzer.
  • Changed-file plus dependency context.
  • Sandboxed test execution.
  • Proof of Work gate.
  • Manual approve or reject.
  • Run, quality, latency, and cost metrics.
Deferred

Earn complexity later

  • Automatic patches or commits.
  • Multi-agent debate on every PR.
  • RepoGraph and vector retrieval.
  • Fine-tuned models.
  • Enterprise billing and policy builder.
  • Support beyond GitHub.
  • Untrusted execution without real isolation.
Risk controls

Failure is visible and safe

Likely risk

  • Webhook retries create duplicate runs.
  • Agent invents evidence.
  • Tests escape worker process.
  • New commit makes old finding stale.
  • Provider usage is missing.

Control

  • Delivery ID and head SHA idempotency.
  • Evidence must map to file, line, or reproducible test.
  • Disposable container; blocked network; hard limits.
  • Cancel superseded workflow; bind findings to SHA.
  • Show unknown; never estimate or convert to zero.
